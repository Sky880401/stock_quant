# 📖 買股信心使用手冊

> 給門外漢的白話版：先懂這些演算法在幹嘛、為什麼有勝率，再用系統指令建立買進信心。

## 一、這些演算法到底在做什麼？（白話）

**核心觀念：所有技術指標，只是「把過去的股價，用數學公式換算成一個買/賣/觀望訊號」。沒有一個是水晶球**，每個只抓一種「股價的習慣」。

| 指標 | 它在看什麼 | 白話比喻 |
|---|---|---|
| **MA 均線** | 最近 N 天的平均價，判斷**趨勢**方向 | 站上長期均線=多頭、跌破=空頭。像「水位線」 |
| **RSI 相對強弱** | 0~100，最近**漲多還是跌多** | >70 超買(可能回檔)、<30 超賣(可能反彈)。像**彈簧** |
| **MACD 動能** | 短期動能 vs 長期動能的差，抓**轉折** | 偵測「加速度」，趨勢轉強或轉弱 |
| **KD 隨機指標** | 類似 RSI，抓超買超賣+轉折 | 跟 RSI 同家族 |
| **布林帶** | 均線±波動範圍，價格碰上下緣 | 碰上緣=過熱、碰下緣=過冷 |

**重點**：每個指標抓的「習慣」不同（趨勢 vs 反轉 vs 動能），同一檔給不同答案很正常。

## 二、為什麼會有「勝率」？

**勝率 = 照這個訊號做，過去歷史上有幾成是賺的。**

怎麼算：過去每次指標喊「買」就假裝買進，過一段時間（例如 20 天）看賺賠 → 賺的次數 ÷ 總次數。

⚠️ 三個一定要記住：
- **勝率是「過去回測」的統計，不保證未來。**
- **樣本要夠多才可信**（3 筆 100% 是假的，要幾十、幾百筆）。
- **不可能 100%**。市場有隨機性，**勝率 53~57% 就很厲害**，有人說 90% 就要懷疑。

## 三、判斷一檔能不能買，該跑什麼？（用你的系統）

系統已把所有面向整合在 `!a` 裡：

1. **`!a <代號>`**：一次算完技術面（MA/RSI/MACD）、基本面（PE/PB/營收）、籌碼面（法人）、上漲機率、風控避雷。
2. **看這幾欄**：
   - 最終建議（BUY / HOLD / SELL）
   - 信心度（**> 0.6** 才有底氣）
   - 上漲機率 + 樣本數（**> 55%** 且樣本多才可信）
   - 法人避雷警示（出現 **heavy** = 紅燈，別追）
   - 距停損 / 目標區間（算划不划算）
3. **看面向一致性（最重要）**：技術說買＋法人也買＋沒避雷 = 信心高；互相打架 = 別追。
4. 想更保險：**`!validate <代號>`**（樣本外驗證，揭穿過度擬合）。

## 四、🟢 買進信心檢查清單（打勾越多越敢買）

1. ☐ `!a` 建議是 **BUY** 且信心 **> 0.6**
2. ☐ 上漲機率 **> 55%** 且樣本夠多
3. ☐ **沒有**法人避雷（heavy）
4. ☐ 多面向**一致**（技術＋籌碼＋基本面沒打架）
5. ☐ 風報比合理（賺的空間 > 賠的空間，至少 1.5 倍）
6. ☐（進階）策略在**多檔驗證**過、勝率 53%+、樣本夠

打勾越多 → 信心越高。但永遠沒有 100%——**一定設停損、控制部位**。

## 五、心法（誠實鐵則）

- 🚫 **沒有聖杯指標**，每個都會錯 → 看「多面向一致」。
- 🚫 **勝率/Sharpe 漂亮但樣本少 = 過度擬合，不信**。
- ✅ **一定設停損、控制部位**，別 all in。
- 📅 系統是**中期波段**（看未來幾週~幾個月），**不是當沖**。
- 💰 賺不賺，最終看**有沒有贏過買進持有（躺著不動）**。
